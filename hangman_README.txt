HANGMAN GAME

Description:
A text-based word-guessing game in which the player guesses a randomly selected word one letter at a time.

Features:
- Randomly selects a word from a predefined list.
- Displays hidden letters using underscores.
- Accepts letter guesses from the player.
- Tracks guessed letters and incorrect attempts.
- Allows up to six incorrect guesses.
- Displays a winning or losing message.

Concepts Used:
- Random module
- While and for loops
- If-else statements
- Strings and lists
- Input and output
- Basic string and list methods

Programming Language: Python

How to Run:
python hangman.py

Purpose:
To practise Python programming through a simple interactive word-guessing game.
